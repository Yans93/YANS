# YANS — Site web pour coachs sportifs

Site vitrine de l'agence YANS : sites web pour coachs sportifs, préparateurs physiques et personal trainers.

## Contenu
- Hero, services, 4 offres (START 44,99 €, PRO 74,99 €, PREMIUM 99,99 €, ULTIMATE 124,99 €), pourquoi YANS, portfolio de démonstrations fictives, FAQ, contact.
- Pages légales (mentions légales, confidentialité, cookies, CGV, CGU) accessibles depuis le footer.
- Structure : `index.html`, `css/styles.css`, `js/main.js` (aucune dépendance, hors polices Google Fonts).

## À compléter avant publication
Dans `js/main.js`, renseignez les objets `CONFIG` (e-mail, Instagram) et `LEGAL` (responsable, statut juridique, adresse, SIRET, TVA, directeur de publication, hébergeur, médiateur). Les champs vides s'affichent en « À COMPLÉTER ».

Les textes légaux sont des modèles non validés juridiquement : à faire relire avant mise en ligne.

## Formulaire de contact
Le formulaire valide les champs puis affiche la demande rédigée. Il n'envoie rien automatiquement : à relier à un service d'envoi de formulaires.

## Cookies
Aucun cookie publicitaire ni de mesure d'audience. La fonction `consentAllows('analytics')` permet de bloquer un futur outil tant que le visiteur n'a pas consenti.

## Lancer en local
Ouvrez `index.html` dans un navigateur.
